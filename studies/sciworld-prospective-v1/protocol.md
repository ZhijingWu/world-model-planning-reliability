# Prospective SciWorld decision study

Protocol fixed on 2026-11-23 before running the prospective search arms. The question is how often a shared write changes the first action selected on a previously unexamined source item under a specified search rule. The program, original 11-state bank, search engine, calibration transitions and tie rule are inherited from the [selected-state study](../sciworld-fixed-work-v1/README.md).

## Design and sample

Use the complete SciWorld test file at PatchWorld dataset revision `9342e2cbee1f8579b5423ed5821f6ad8a81ab773`. Exclude the first 100 test trajectories, every source item occurring in that historical prefix, and every source item in the complete training split. Identify source items by the UTF-8 SHA-256 of the metadata item ID and validate the correspondence with the numeric task index. A trajectory must contain at least three distinct logged commands. Outcome, mutation, predicted score, replay success, recorded reward and terminal flag play no role in selection. No prospective root-action outcome is inspected in setup. No pilot on these tasks is used.

1. Group eligible trajectories by item. In each group preassign one trajectory, the one with lowest SHA-256 of compact UTF-8 JSON `["trajectory", item_hash, trajectory_index]`. Preassign one step in it by the lowest digest of `["step", item_hash, trajectory_index, step]`. Ties use the lower index. State identifiers are zero-based trajectory and transition positions, with an additional global transition index flattened over the full test file.
2. Reconstruct the state immediately after the logged current-observation correction, using the Stage 2 sequence of prediction on a fresh deep copy and next-observation correction at every preceding step. Exclude a preassigned state whose canonical value equals any correction-state root in the first 100 test or first 32 training trajectories. Among identical prospective root values keep the lexicographically lowest source-item digest. Retain the other exclusions in the manifest. No alternate representative is drawn.
3. Each remaining representative has a fixed candidate list and goal walk. Seed an independent Python RNG with the integer SHA-256 digest of `["tree", item_hash, trajectory_index, step]`. Starting with distinct logged actions in first-occurrence order, apply the Stage 2 sequence: shuffle, take up to four, shuffle again, choose a uniform walk length from 2, 3 or 4, then draw each walk action with replacement. The reference goal is the resulting original-model state on fresh per-edge copies. The first three candidates form the search tree. Include every goal, including trivial ones. Candidate and walk generation is independent of sample membership.
4. Sort the eligible frame by source-item digest. Draw `random.Random(20261123).sample(frame, min(64, len(frame)))` without replacement, exactly once. Fixing the target at 64 limits ordinary searches to 13,824 transitions. For a large frame, 64 states have about 12 percentage points of worst-case 95% normal-approximation half-width before finite-population correction. This precision calculation and work budget motivate the fixed size. Do not increase it after seeing outcomes. Freeze the manifest, code, action and goal fingerprints before running any arms.

The finite population consists of one eligible, preassigned state per distinct held-out source item after canonical-root exclusions. Each sampled state belongs to a different source item and trajectory. A common generated program, related tasks and shared state vocabulary can still give correlated behavior across items. The primary estimand applies to this finite frame of representatives. It does not imply a transition-weighted frequency, stochastic-policy frequency or native-environment prevalence. [Pinned dataset](https://huggingface.co/datasets/HKBU-KnowComp/patchworld-trajectories/tree/9342e2cbee1f8579b5423ed5821f6ad8a81ab773/sciworld)

## Search, interventions and outcomes

Use WCTR release `wctr-runtime-repair-2026-11` at `4ba67940378b959a07e63426cf4d3d3bdaf93c86`. For every state and each of the six lexicographic permutations of three roots, reset the state and model for Raw, independent per-edge Full Copy and WCTR. Initialize WCTR using the same first 32 training transitions on each order. Keep child order at 0,1,2. Expand each root and its three children immediately for exactly 12 transitions. Freeze each observed value and alias fingerprint as the edge executes. Preserve scalar leaf scores, parent and root changes, runtime work, tied actions and replay outcomes. Calibration, independent two-action replay and any rescue runs are counted separately. All six orders are repeated measurements within one state.

- **Primary endpoint.** A unique sampled state is positive if any of its six orders changes the selected root action between Raw and Full Copy. A leaf scores one point per matching top-level goal field. A root receives its best leaf score. Equal scores resolve to the lowest frozen index, first among children for each root and then among roots. The denominator is the number of sampled states; report any missing primary outcome and give bounds rather than replacing it. Full Copy must preserve parents and agree across orders path by path. WCTR must preserve parents and match the reference. A broken control is a research-integrity issue.
- **Secondary outcomes.** Report changed parents, corresponding branch inputs, leaf and root scores, weak rankings and optimal-action sets; include a change in strict-winner presence (one maximizer versus multiple). Count how many states have at least one changed order and report order- and edge-level denominators separately. Report whether the selected leaf meets the exact whole goal on independent replay. A false goal requires an exact search claim followed by a replay miss. Record WCTR fallback, deoptimization and added witness paths.
- **Tie sensitivity.** Compare the full maximizer sets and weak rankings. Recompute decisions with the highest frozen index winning ties as one predeclared alternative. Show the joint original/alternative outcomes; select no rule after seeing results. These are descriptive secondary measures.
- **Causal test.** On a root decision difference, use the earliest sustained changed value from a raw writing edge that reaches a later sibling, in the frozen engine's traversal order. Rerun the same raw order on a pristine root with only that edge executed on a fresh copy. Require recovery of the affected sibling input and reference first action for a verified single-edge rescue. Separately distinguish score-only effects, unresolved decisions with multiple candidate writes, unresolved single-candidate or untraced effects, and failed controls. Multiple observed writers do not establish that multiple writes are necessary. The second action and exact goal on the protected reference path remain separate questions.
- **Uncertainty.** Report the unique-state proportion and an equal-tailed 95% confidence set for the number of positives in the fixed finite population, divided by frame size. Invert the hypergeometric tails for simple random sampling without replacement; include boundary values for zero or all positives. Count a source item only once. This interval addresses the random draw over the fixed frame. It omits uncertainty about the generator, unexamined programs, alternative scoring rules and environment success.

The program-level comparison uses the same generated model for all three arms. Absolute environment correctness, selective-copy speed and performance relative to native interaction are outside these outcomes. [Frozen fixed-work engine](../sciworld-fixed-work-v1/sciworld_study_engine.py)
