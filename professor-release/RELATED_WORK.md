# Where this work fits

WCTR asks what happens when two calls to the **same executable transition** share mutable state through the caller. The independent reference runs the original transition on a fresh deep copy at every search edge. This isolates an execution error from the harder question of whether a learned transition accurately represents an environment. The distinction can be tested directly because both the writing edge and its later sibling are observable. [Frozen comparison](../studies/sciworld-fixed-work-v1/public/report.md) · [Prospective study](../studies/sciworld-prospective-v1/report.md)

[Authors’ paper](https://people.cs.umass.edu/~moss/papers/isca-1993-trans-mem.pdf) · [Runtime contract](../docs/SUPPORTED_STATE.md) |

**Empirical contribution.** The retained trace identifies where a correct returned successor gave a sibling the wrong input. A prospective, source-disjoint test estimates how often this affected the chosen first action for one specified planner and frame. **Engineering contribution.** The restricted runtime tests branch preservation against full copying and provides a conservative fallback. The SciWorld arms exercised that fallback. The research makes no theoretical priority or general speed claim. Primary papers and the pinned implementation were checked on 2026-11-23.
