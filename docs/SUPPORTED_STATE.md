# Supported-state contract and API

The intended operational target for one instrumented transition is (1) parent values restored after the call, including supported exceptional exits, and (2) returned values equal to the same model's raw transition on a full deep copy. This is an implementation target checked on finite workloads, not a formal proof or arbitrary-Python guarantee.

```python
from wctr import Adapter, compile_source
namespace = compile_source(trusted_python_source, "model.py")
model = namespace["Model"]()
adapter = Adapter(model, "wctr")
adapter.calibrate([(belief, action)])  # Optional finite execution witnesses
successor = adapter.transition(belief, action)
```

`compile_source` executes trusted Python. Supply a model with `predict_belief(state, action)` and a deterministic transition on the state described below. Use an uninstrumented instance of the same model for the `deepcopy` and `raw` controls.

Calibration is optional. It runs model calls on copied inputs and retains the observed write paths. After calibration the adapter resets its work counters and keeps its witnesses. Later successful calls can update the same paths when the journal captures an unexpected write. The action signature is the lowercased prefix before the first literal space after trimming the action string. For example, `"Pick up box"` and `"pick key"` share the signature `"pick"`. A learned path predicts which objects to copy before the next call.

## Scope and assumptions

- The selective input is an exact dict/list/tuple graph with scalar keys and leaves of exact type `NoneType`, `bool`, `int`, `float`, `complex`, `str` or `bytes`. The action must also be a scalar. In an admitted source module, subscript stores and deletions receive a barrier wherever they occur, including loop and unpacking targets. Subscript augmented assignment uses Python's native operator and original RHS scope. Name-bound augmented assignment and annotated assignment select native Full Copy for the module. The same policy covers reflective calls and unreviewed syntax. [AST coverage matrix](AST_COVERAGE.md)
- A direct mutator call records the actual built-in receiver, including the first argument of an unbound built-in method. Taking a method as a value generally selects ordinary execution on a deep copy. This preserves callback identity and protects writes through native consumers such as sort keys and mapping constructors. On the selective path an unverified callable, mutator receiver or captured source-declared model mutator is explicitly rejected. If the model catches the rejection and returns, the adapter still rejects the transition and restores its journal. [Guard and mutator names](../src/wctr/isolation.py)
- Dotted names such as `case Action.clear:` keep Python's pattern grammar. The match subject, guards and executable case bodies still receive instrumentation. A class pattern can extract a raw method through implicit attribute lookup, as in `case list(append=callback)`. During selective execution, reaching a `match` that contains a capture or `as` binding under a listed mutator keyword rejects the transition after evaluating the subject and before trying any case. This conservative rule also covers partial bindings from failed cases. The raw Full Copy path can run that pattern. Custom pattern protocols with side effects and hidden attributes supplied by user-defined `__match_args__` are outside scope. [Python AST pattern nodes](https://docs.python.org/3.13/library/ast.html#pattern-matching) · [PEP 634 pattern and guard semantics](https://peps.python.org/pep-0634/)
- The compiler marks containers created by literals and comprehensions as private. A method called `copy` or a variable called `list` can return a parent alias. Neither name establishes fresh ownership.
- A protected entry with an uncertified implementation or model class runs once on a full copy. Otherwise the adapter checks the current input, including dictionary keys and values and list/tuple elements. A reachable set, `defaultdict`, container subclass or non-scalar leaf selects Full Copy before the model runs. A copy can change the order of a set, and a missing-key read can change a `defaultdict`. The initial-belief `defaultdict` policy still applies. The optional `_wctr_raw_model` must implement the same transition. Fallback requires faithful `deepcopy` and deterministic effects confined to the copied input.
- With no witness for this action, discovery keeps a visited-ID set to handle aliases and cycles. The journal builds its reverse-edge and witness-path index before the first intercepted potential write to a receiver whose ownership is unknown. With a witness, one pass builds the index and checks container types, stopping early on fallback. Both routes see changes made between calls, including when the root has the same identity. Clean reads still scale with the amount of reachable input. [AST repair costs and controls](../diagnostics/ast-gate/README.md)
- Alias closure preserves tested dict/list sharing and cycles. When selective copying encounters a back-edge to an unfinished tuple, it deep-copies the whole graph being forked. This can occur while forking the input or grafting the output. Each such fallback increments `full_clones` in the current runtime. At `3c902203`, these copies contributed to the copied-container count only. An archived zero in `full_clones` cannot establish the absence of tuple-cycle fallbacks.
- State must not be concurrently mutated or exposed to external observers during speculative execution and rollback.
- Untouched objects can remain shared between parent and successor. Arbitrary direct mutation after a call is outside the supported usage; subsequent rollouts should pass through the adapter.

The parent graph must be reachable by the model only through its state argument. Model attributes, closure cells, a separate action or external globals retaining the original parent can invalidate even the raw-on-deep-copy reference. The contract assumes ordinary, unmodified compiler and model namespaces, materialized successor values, and graphs within Python's recursion and memory limits. On an exceptional exit after journaled writes, the adapter preserves data-valued exception arguments and `AttributeError.obj`, including sharing in the cause/context chain. An opaque payload that cannot be detached triggers an explicit rejection. External effects, frame/traceback inspection, arbitrary exception attributes, I/O and uncontrolled random state are outside the value contract.

## What the tests establish

The 44 tests comprise the seven original cases, ten initial audit regressions, six callback/pattern tests, three entry-scan tests, three regression-first AST blockers and fifteen independent semantic tests. The independent oracle compiles ordinary source, checks exceptions and compares cyclic graph structure and alias identities. [Blocker cases](../tests/test_ast_semantics.py) · [Independent differential tests](../tests/test_semantic_gate.py) · [Release gate](../tools/release_gate.py)

The completed native study recorded zero parent/output value failures in 33,692 WCTR branch transitions on historical revision [`3c902203`](https://github.com/ZhijingWu/world-model-planning-reliability/tree/3c9022030323bd22e05b3f5276531eaa542cb1eb). The four protected methods together accounted for 134,768 checks. Those counts describe the historical workload. The current regression suite uses separate fixtures.
