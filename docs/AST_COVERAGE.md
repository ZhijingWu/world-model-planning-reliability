# AST semantic release gate

The public comparison is an ordinary Python model running on one fresh deep copy of the parent. The gate checks returned values, alias topology within the result, the original parent's values and object identities, and the type and arguments of observable exceptions. The parent must also survive a partially executed write or a failing `finally` block. This claim concerns trusted, deterministic, state-confined models on CPython 3.10–3.13. [Input contract](SUPPORTED_STATE.md)

## How a transition is selected

`compile_source` examines the entire module before executing it once. Every node must belong to an explicitly reviewed AST family, and the additional checks below must pass for the module to receive instrumentation. An unlisted family, including one added by a later Python version, selects ordinary compilation. Both compiler paths use `dont_inherit=True`, so the input source controls its own future flags. At transition entry the adapter verifies the callable's code and model class, checks the action and inspects the live input before selecting the journal. A native fallback starts the original transition once on a private graph. It increments `full_clones`. It does not retry an already-started model call. [Implementation](../src/wctr/isolation.py)

## Coverage matrix

The classification describes the form in an otherwise eligible module. A full-copy trigger elsewhere in the module takes precedence. The AST compiler itself checks whether the original syntax is valid.

| Python form or AST family | Classification | Effect on caller-owned state |
| --- | --- | --- |
| `Name` assignment, unpacking into names, `del name`, `NamedExpr`, ordinary argument and exception bindings | SAFE_BY_LANGUAGE_SEMANTICS | Rebinding changes a binding. The RHS and any executable child expressions still pass through the transformer. |
| `Assign`, `Delete`, `Subscript(Store/Del)`, `Slice`, chained assignment, tuple/list and starred targets | SUPPORTED_AND_GUARDED | Only the target base receives a write barrier. Python evaluates the RHS, target bases and indices in native order. Each actual store or deletion records its receiver, including earlier targets if a later target raises. |
| `AugAssign` with a subscript target, including a slice | SUPPORTED_AND_GUARDED | Python evaluates the base and key once, fetches the old value, evaluates the RHS in its original scope, applies its native in-place opcode and then stores. The barrier records a mutable old value before the opcode and the container before the store. This covers partial mutations when the opcode or final store fails. |
| `AugAssign` with a name or attribute target | SAFE_FULL_COPY_FALLBACK | An alias can refer to the parent before a subsequent rebinding. Native Python handles in-place dispatch and rebinding on the copied graph, including exceptions. Numeric-only name updates also select this conservative route. |
| `AnnAssign`, with or without a value, in a function, class or module | SAFE_FULL_COPY_FALLBACK | Compile the original annotated statement. Python controls namespace-specific annotation evaluation, side effects, order and exception propagation. |
| `Subscript(Load)`, scalar literals, arithmetic, comparisons, Boolean operators, conditional expressions | SAFE_BY_LANGUAGE_SEMANTICS | Ordinary reads and operators on supported plain data retain their Python semantics. Executable children are visited. User-defined operator protocols require the assumptions in the input contract. |
| `Call` of a listed bound built-in mutator or an unbound descriptor | SUPPORTED_AND_GUARDED | Check the resolved callable at invocation. Record its bound receiver or the descriptor's first positional argument. An ordinary wrong-receiver argument error comes from the descriptor. |
| Attribute read that takes a callable as a value, including `cb = events.append`, class-level storage, and native callback arguments | SAFE_FULL_COPY_FALLBACK | A native consumer can invoke a callback with no Python `Call` node. Original-source execution on a copy also preserves method identity, equality and descriptor binding. The next row covers the specific conservative rejection. |
| Unknown callable in an otherwise admitted call, unknown mutator receiver, or an ambiguous captured mutator declared as a model method | EXPLICITLY_REJECTED | A journal rejection occurs before the unverified invocation or callable exposure. A model that catches the error and returns cannot publish a successor. The adapter restores earlier writes. |
| Attribute stores/deletes, explicit dunder lookup, reflective built-ins, opaque imports, decorators, inheritance and custom special methods | SAFE_FULL_COPY_FALLBACK | Ordinary source executes on a copy before any speculative invocation. External effects through globals, descriptors or foreign objects still require caller control. |
| `For`, `While`, `If`, `IfExp`, `Break`, `Continue`, `Pass`, `Return` and expression statements | SAFE_BY_LANGUAGE_SEMANTICS | Native control flow fixes the evaluation order and selected branches. A subscript loop target uses the store barrier on each iteration. |
| `List`, `Dict`, `Set` displays and their eager comprehensions | SUPPORTED_AND_GUARDED | Fresh allocated containers are private. Their existing children can still be shared. Subscript targets in comprehension clauses have the same write barrier. A helper named `copy` or a constructor alias confers no ownership. |
| `FunctionDef`, nested closures and calls to compiled helpers | SUPPORTED_AND_GUARDED | The original lexical scope is retained. The call check recognizes the actual compiled function. A `nonlocal` or `global` declaration selects native Full Copy for the module. |
| `Match`, `match_case`, value, sequence, mapping, class, capture and OR patterns | SUPPORTED_AND_GUARDED | Pattern grammar is left intact. The subject, guards and case bodies are visited. Capture names bind existing objects. A class-pattern keyword outside the admitted mutator names selects native Full Copy. |
| Implicit mutator capture such as `case list(append=cb)` | EXPLICITLY_REJECTED | On the selective route, evaluate the subject and reject before any pattern can bind, including partial binding during a failed match. |
| `Try`, `ExceptHandler`, `finally`, literal built-in exception construction | SUPPORTED_AND_GUARDED | Python runs the model's handlers and cleanup. Before rollback the adapter detaches public `args` and `AttributeError.obj` across the cause/context chain with a single copy memo. Values and sharing then reflect the completed `finally` blocks. The adapter resets its context even if restoration raises. |
| Opaque objects in public exception payloads on a journaled exit | EXPLICITLY_REJECTED | Scalars, built-in data containers and data-only `SimpleNamespace` receivers can be detached. An opaque live receiver such as an iterator can retain an alias into the restored parent. The boundary rejects it and rolls back. Traceback frames, arbitrary custom exception metadata and external resources are outside the value contract. |
| Dynamic `Raise`, reraises, explicit causes, mutable exception arguments and shadowed exception constructors | SAFE_FULL_COPY_FALLBACK | Rollback could otherwise change a list retained by an exception. Literal raises qualify for selective execution only when their built-in exception names have no assignment, parameter or import binding in the module's symbol tables. |
| Module/class definitions, `arguments`, `keyword`, comparison/operator and context markers | SAFE_BY_LANGUAGE_SEMANTICS | They retain their native binding or evaluation role. Actual calls, stores and definition expressions are checked separately. The one admitted import is `from types import SimpleNamespace`, including an alias. |
| `With` and its targets, async forms, `Yield`, `YieldFrom`, generator expressions, lambdas, wildcard imports, `Assert`, `TryStar`, type aliases/parameters, formatted strings and other unlisted AST families | SAFE_FULL_COPY_FALLBACK | The compiler retains the original module. This also covers implicit context-manager calls and writes deferred beyond the transition. The value contract is for materialized successor graphs. |
| External aliases into the parent, concurrent observation, mutation of compiler globals by the host, unfaithful `__deepcopy__`, I/O and shared mutable model state | UNSUPPORTED_OUT_OF_CONTRACT | Copying the supplied input cannot isolate a second route to the original object or reverse effects outside that input. The package executes trusted code. |

The gate found no unresolved class among the documented forms it exercised. The default for unreviewed syntax is native Full Copy. The gate supplies finite evidence for this scope.

## Helper hygiene

The transformer inserts helper keys containing a colon directly into the AST. Python identifiers, parameters, imports, pattern bindings and local or global declarations cannot spell those names. Wildcard imports and dynamic namespace access select ordinary compilation before helper installation. Code and class eligibility metadata use runtime-owned object keys. The operator itself stays in the original AST, so a source binding named `Add` has no role in dispatch.
